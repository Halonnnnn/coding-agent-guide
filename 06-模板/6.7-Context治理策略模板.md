# 6.7 Context Trust & Governance Policy（模板）

```
来源名称：[文档 / 系统名]
来源类型：官方文档 / 项目 Wiki / 代码注释 / 历史决策 / 口头约定
维护者与更新频率：[谁维护、多久变动一次]

权威事实：[该来源能回答的事实，如 API 参数定义、验签算法]
非权威事实：[它不能回答的事实，如当前运行状态、沙箱行为]
信任级别：权威（可直接引用）/ 参考（需与代码核对）/ 待验证（需人工确认）

Metadata：版本号 / 生效日期 / 最近核验时间 / 核验方式
使用策略：
  - 可直接引用的条件：[...]
  - 需运行时验证的事实：[验证命令或接口]
  - 需人工确认的事实：[...]
冲突规则：[与代码、测试、其他文档冲突时的优先级，
  如：运行时实测 > 当前代码 > 官方文档 > Wiki；冲突本身要记录]
失效处理：[核验失败或来源过期时标记为信息缺口，不用推测填补]
```

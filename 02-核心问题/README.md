# 二、核心问题

Coding Agent 能较好地完成目标明确、边界清晰的单项任务，但在持续迭代中，质量和稳定性会明显波动。以下六组问题相互关联：**信息缺失或历史干扰导致目标定位偏差，偏差导致修改对象或方案出错，错误修改被局部补丁掩盖，最终在验证阶段暴露，带来返工和成本上升。**
